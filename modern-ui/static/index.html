A QUICK GUIDE

From a note to an instrument.

01 - Import

Choose a full recording or individual note files. Full sequences stay in Sources, separate from the note checklist and its batch actions.

02 - Split

Choose a source and adjust the noise threshold, quiet gap and tail margin. Find notes proposes regions. You can also skip detection and add regions manually.

03 - Review splits

Listen to the cuts, zoom into a region, edit its start/end and key, and exclude unwanted sounds. Add, divide or merge regions as needed. Create note samples when ready; creating again adds new copies.

04 - Loops & trim

Detect selected notes, or the visible list. Approved notes and manual edits are protected. Drag markers, type times, or place attack, loop, release and tail markers at the waveform cursor.

Open Add or refine a loop near chosen points to enter approximate start and end points. Find best nearby seam stays within your chosen distance of both points. Search does not change markers. Try & listen applies a suggestion; Use these exact points creates a manual loop. Undo restores earlier edits.

Trimmed sample auditions from the attack/trim start through tail end. Loop repeats the sustain; Release plays from the release marker. Source PCM stays intact.

Approve after listening, individually or in bulk. Choose Testing only for a trial export. Batch approval uses checked notes, or the visible list if none are checked, and lists invalid notes it skips.

05 - Export & play

Export approved notes with loop/cue metadata or as split WAVs or SFZ. Enable Trim outside attack and tail markers to export the trimmed range. The mini player can combine saved stop snapshots.

You can return to any tab. Split drafts and the selected stage autosave with the project. Original files stay untouched.
